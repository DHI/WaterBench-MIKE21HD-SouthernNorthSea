# Output sample

A one-week extract (2023-01-01 to 2023-01-08) of the model results, so that the notebooks in [`../code`](../code) can be run without downloading the full output:

- `Area.dfsu`: surface elevation and u/v current velocity in the full domain.
- `Points.dfs0`: the same variables at the observation stations.

The full two-year results (2022-2023) are on [Zenodo](https://doi.org/10.5281/zenodo.14929387) (`MIKE21HD-SouthernNorthSea-output.zip`). The extract is made by `.preprocessing/subset_modelresult.ipynb`.
